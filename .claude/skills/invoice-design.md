# 发票网站设计规范

## 设计原则
- **风格**：商务简约，干净专业
- **配色**：深蓝(#1e3a5f) + 白(#ffffff) + 浅灰(#f5f7fa) + 强调绿(#10b981)
- **字体**：IBM Plex Sans（标题）+ Source Sans Pro（正文）
- **布局**：左侧导航 + 右侧内容区，充足留白

## 避免
- 紫色渐变、过度圆角
- Inter/Roboto/Arial 字体
- 过多动画效果
- 密集信息堆叠

## 组件风格
- 表格：简洁边框，斑马纹背景
- 按钮：直角或微圆角，主色实心
- 表单：清晰标签，充足间距
- 卡片：轻微阴影，无过度装饰
